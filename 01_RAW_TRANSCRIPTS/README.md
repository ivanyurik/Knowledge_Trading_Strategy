# Canonical Transcripts

Назва каталогу 01_RAW_TRANSCRIPTS є legacy/compatibility naming. Вона НЕ означає, що тут зберігається raw ASR.

Тут зберігаються тільки corrected canonical transcripts після повного transcription correction pass.

## Заборонено

- raw ASR transcript;
- backup/raw copy;
- unreviewed transcript;
- audit copy of raw ASR;
- використання uncorrected ASR як canonical source.

## Correction gate

- HIGH confidence → виправити.
- MEDIUM confidence → NEEDS_REVIEW.
- LOW confidence → не вгадувати.

Canonical transcript має бути читабельним, технічно точним там, де контекст однозначний, і faithful до змісту розмови.
