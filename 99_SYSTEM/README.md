# System Documentation

Цей каталог містить операційні правила Project Knowledge Manager.

Ключові файли:
- `AGENT_INSTRUCTIONS.md` — поведінка агента.
- `METHODOLOGY.md` — методологія knowledge base.
- `PROCESSING_CHECKLIST.md` — completion gate.
- `FILE_FORMAT.md` — формати артефактів.
- `CHANGE_POLICY.md` — правила змін.
- `PROCESSING_REPORTS/` — звіти обробки CALL.

Ключовий navigation artifact:
- `00_INDEX/TOPIC_INDEX.md` — жива картотека тем та маршрутів до джерел.

Єдине джерело операційної логіки — актуальна методологія Project Knowledge Manager. Старі моделі raw transcript не застосовуються.
