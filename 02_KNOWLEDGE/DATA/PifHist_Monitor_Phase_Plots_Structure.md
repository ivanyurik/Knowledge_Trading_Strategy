В текущем файле **значения плотов разделены по назначению: состояние, направление, разрешение поиска, событие и цена**. Поэтому единица или двойка имеют смысл только вместе с названием плота.

Основные объявления находятся в [блоке вывода фаз](</mnt/c/Users/G/Desktop/TV pine scripts/PifHist Monitor/PifHist Monitor Phase.md:2728>). Ниже — именно фазовая часть.

В таблицах указаны полные актуальные названия: значения кодов расшифрованы в скобках через `;`, а ценовые плоты фаз помечены `(Price)`. В пояснениях и примерах названия сокращены для удобства чтения. `na` означает отсутствие значения; это не ноль.

**Единый словарь фаз: аббревиатуры, полные названия и обозначения в индикаторе**

Расшифровки взяты из [документа «Алгоритм фаз»](</mnt/c/Users/G/Desktop/TV pine scripts/PifHist Miro/Алгоритм фаз.md:1>). Аббревиатура, полное русское название и английское обозначение в индикаторе относятся к одной и той же фазе. Код её типа выводится в `Phase - State (1 = BVN; 2 = Impulse; 3 = Stop And Flat)`.

| Аббревиатура в алгоритме | Полное название | Обозначение в индикаторе | Код в `Phase - State` | Текст метки на графике |
|---|---|---|---|---|
| **БВН**; латиницей **BVN** | **Борьба в начале** | `BVN` в расшифровке состояния; `Initial Struggle` в названии события начала | `1` | `BVN` |
| **ИМД**; латиницей **IMD** в комментариях к коду | **Импульсное движение**; в тексте также «импульс» | `Impulse` | `2` | `IMP` |
| **О+Ф**; латиницей **O+F** в комментариях к коду | **Остановка + флет**; в тексте также «остановка и флэт» | `Stop And Flat` | `3` | `S+F` |

`BVN` — запись русской аббревиатуры БВН латиницей. `Initial Struggle` — английское название той же фазы. `IMP` сокращает английское `Impulse`, а `S+F` — `Stop And Flat`. Метки `BVN`, `IMP`, `S+F` отмечают события начала; текущее состояние на каждой свече нужно читать по `Phase - State`.

Связь с полными названиями событий:

| Фаза из алгоритма | Плот события начала |
|---|---|
| БВН — борьба в начале | `Phase Start - Initial Struggle (0 = No Start; 1 = Start)` |
| ИМД — импульсное движение | `Phase Start - Impulse (0 = No Start; 1 = Start)` |
| О+Ф — остановка + флет | `Phase Start - Stop And Flat (0 = No Start; 1 = Start)` |

У всех трёх событий `1` означает, что отмечено начало соответствующей фазы, а `0` — что такого события на свече нет. Например, `1` в событии начала О+Ф соответствует запуску фазы с кодом `3` в `Phase - State`: у события и состояния разные шкалы значений.

**Индексы фаз в алгоритме: БВН0, БВН1, О+Ф2, ИМД2**

Цифра после аббревиатуры обозначает место конкретной фазы в рассматриваемой последовательности:

| Индекс в алгоритме | Значение |
|---|---|
| `0`, например `О+Ф0` / `БВН0` | Фаза, предшествующая последней такой фазе. |
| `1`, например `О+Ф1` / `БВН1` | Последняя такая фаза, от которой рассматривается дальнейшее развитие. |
| `2`, например `О+Ф2` / `ИМД2` | Новая фаза в рассматриваемой последовательности. |

**Индекс последовательности, код типа фазы и номер половины глобального тренда — разные значения.** Например, БВН0 и БВН1 имеют один код типа — `Phase - State = 1`; О+Ф2 имеет код `3`. В записи ИМД2 индекс `2` означает новую фазу, а значение `Phase - State = 2` отдельно означает её тип — импульсное движение. Индексы `0/1/2` из алгоритма отдельным плотом не выводятся. Плот `Global Trend - Half (1 = First Half; 2 = Second Half)` показывает только половину глобального тренда.

**Другие обозначения алгоритма и связанные плоты**

| Термин или сокращение | Расшифровка и связь с индикатором |
|---|---|
| **б/м** | Бычье / медвежье направление: `Bullish` = `1`, `Bearish` = `-1`. Направление фазы показывает `Phase - Direction (-1 = Bearish; 1 = Bullish)`, глобального тренда — `Global Trend - Direction (-1 = Bearish; 1 = Bullish)`. |
| **BG** | `Big Guy`. Например, BG 0,5 соответствует `Big Guy Fibo 0.5 (Price)`, BG 0,382 — `Big Guy Fibo 0.382 (Price)`, BG 0,618 — `Big Guy Fibo 0.618 (Price)`. |
| **Синий / жёлтый столб Big Guy** | События `Blue` / `Yellow`. Их цены открытия выводятся в `Big Guy - Blue Signal Open (Price)` и `Big Guy - Yellow Signal Open (Price)`. |
| **4H / 1W** | Четырёхчасовая / недельная свеча. `4H` в названиях `Impulse Entry - ... 4H Divergence` указывает таймфрейм сигнала входа. |
| **Окно поиска старта ИМД**, окно попыток | Разрешение искать 4H-вход. Ему соответствует `Phase - Impulse Search Window (0 = Closed; 1 = Open)`: `0` — закрыто, `1` — открыто. |
| **Окно поиска новой О+Ф** | Разрешение ожидать сигнал начала остановки + флета. В коде это `flat_window`; отдельного плота нет. Открытие окна ещё не означает `Phase - State = 3`. |
| **Попытка старта ИМД** | Принятый 4H-вход, который до подтверждения ещё может быть отменён стопом. Событие входа отмечается соответствующим `Impulse Entry - ...`; состояние уже имеет код `2`. |
| **Подтверждённое / особое ИМД** | Варианты импульсного движения по правилам алгоритма. В `Phase - State` также имеют код `2`; отдельных кодов для подтверждения и особого режима нет. |

Правила окон и попыток описаны в [пунктах 1–3 алгоритма](</mnt/c/Users/G/Desktop/TV pine scripts/PifHist Miro/Алгоритм фаз.md:33>), особого ИМД — в [пункте 4 и альтернативе по трём телам](</mnt/c/Users/G/Desktop/TV pine scripts/PifHist Miro/Алгоритм фаз.md:70>). Ниже приведены значения и особенности каждого плота.

**Глобальный тренд: два плота**

| Название плота | Значения | Что означает |
|---|---|---|
| `Global Trend - Direction (-1 = Bearish; 1 = Bullish)` | `-1` / `1` | `-1` — выбран медвежий глобальный тренд; `1` — бычий. Направление берётся из настройки. |
| `Global Trend - Half (1 = First Half; 2 = Second Half)` | `1` / `2` | `1` — первая половина глобального тренда; `2` — вторая. |

«Половина» здесь определяется **ценовым условием**, а не половиной прошедшего времени:

- В бычьем тренде вторая половина начинается, когда `high` превышает максимум, накопленный кодом до старта тренда.
- В медвежьем — когда `low` становится равным или ниже 50% максимума, накопленного кодом к этому моменту.
- Обратного переключения `2 → 1` в этом расчёте нет.

Отдельный плот времени начала второй половины удалён. Её начало определяется по открытию 4H-свечи, на которой `Global Trend - Half` изменился с `1` на `2`. Логика — [в функции определения половины](</mnt/c/Users/G/Desktop/TV pine scripts/PifHist Monitor/PifHist Monitor Phase.md:1753>).

**Текущая фаза: четыре плота**

| Название плота | Значения | Что означает |
|---|---|---|
| `Phase - State (1 = BVN; 2 = Impulse; 3 = Stop And Flat)` | `1` / `2` / `3` | `1` — БВН, борьба в начале; `2` — ИМД, импульсное движение; `3` — О+Ф, остановка + флет. |
| `Phase - Direction (-1 = Bearish; 1 = Bullish)` | `-1` / `1` | Текущее направление фазы/поиска: `-1` — медвежье; `1` — бычье. |
| `Phase - Impulse Search Window (0 = Closed; 1 = Open)` | `0` / `1` | `0` — поиск подходящей 4H-дивергенции для входа закрыт; `1` — разрешён. |
| `Phase - Active Entry Stop (Price)` | Цена / `na` | Стоп текущей попытки, пока её сетка заблокирована, если стоп задан в CSV. |

Эти поля описывают состояние **на каждой свече**. Например, последовательность `Phase - State`:

```text
1, 1, 1, 2, 2, 2, 3, 3
```

означает три свечи БВН, затем три свечи импульса, затем О+Ф.

Здесь есть несколько существенных разграничений:

- **Направление глобального тренда и направление фазы независимы.** В бычьем глобальном тренде может идти медвежья фаза.
- `Impulse Search Window = 1` означает разрешение поиска. Для нового входа дополнительно нужны подходящий сигнал, свободная сетка и остальные условия. При уже зафиксированном входе этот плот может оставаться равным `1`.
- Этот плот выводит внутренний `search_open`. Внутреннее **окно ожидания О+Ф — `flat_window` — отдельно не выводится**.
- `Active Entry Stop = na` не доказывает отсутствие входа: вход возможен без записи стопа в CSV.

**Ноль и пустое значение имеют разный смысл**

Внутри программы фаза до запуска имеет код `0`, но **в `Phase - State` этот ноль заменяется на `na`**.

Поэтому:

| Значение | Как читать |
|---|---|
| `Phase - State = na` | Фаза ещё не запущена либо модуль выключен. |
| `Phase - Impulse Search Window = 0` | Фаза существует, но поиск входа закрыт. |
| `Phase - Impulse Search Window = na` | Активной фазы нет либо модуль выключен. |

Глобальные плоты также пустые до старта глобального тренда или при выключенном модуле. При этом глобальный тренд уже может начаться, а первая фаза ещё не появиться.

**Начала фаз: три отдельных признака события**

Они реализованы через `plotshape()`:

| Название | Событие |
|---|---|
| `Phase Start - Initial Struggle (0 = No Start; 1 = Start)` | Запуск/перенаправление БВН — борьбы в начале. |
| `Phase Start - Stop And Flat (0 = No Start; 1 = Start)` | Запуск О+Ф — остановки + флета. |
| `Phase Start - Impulse (0 = No Start; 1 = Start)` | Запуск ИМД — импульсного движения. |

Это булевы признаки: **`1` — событие отмечено на этой свече, `0` — не отмечено**. На графике им соответствуют ромб `BVN`, квадрат `S+F` и треугольник `IMP`.

Разница с состоянием выглядит так:

```text
Phase - State:          1  1  2  2  2
Phase Start - Impulse:  0  0  1  0  0
```

Но эти маркеры **не являются полным журналом всех изменений состояния**: например, восстановление предыдущего диапазона может вернуть фазу без нового маркера начала. Кроме того, настройка «Показывать начала фаз» отключает сами эти признаки в `plotshape`, тогда как расчёт состояния продолжается. Объявления — [здесь](</mnt/c/Users/G/Desktop/TV pine scripts/PifHist Monitor/PifHist Monitor Phase.md:2721>).

**Попытки входа: четыре отдельных признака события**

Рядом есть ещё четыре `plotshape()` для принятых 4H-входов. У каждого `0` означает отсутствие события входа, `1` — принятую попытку входа. Это не признак того, что позиция остаётся открытой на последующих свечах.

| Название | Событие |
|---|---|
| `Impulse Entry - Classic Bullish 4H Divergence (0 = No Entry; 1 = Entry)` | Вход по классической бычьей 4H-дивергенции. |
| `Impulse Entry - Classic Bearish 4H Divergence (0 = No Entry; 1 = Entry)` | Вход по классической медвежьей 4H-дивергенции. |
| `Impulse Entry - Hidden Bullish 4H Divergence (0 = No Entry; 1 = Entry)` | Вход по скрытой бычьей 4H-дивергенции. |
| `Impulse Entry - Hidden Bearish 4H Divergence (0 = No Entry; 1 = Entry)` | Вход по скрытой медвежьей 4H-дивергенции. |

Эти события не являются отдельными кодами фаз. У двух скрытых входов маркер на графике смещён на следующую 4H-свечу (`offset=1`).

**Big Guy: два плота с ценой события**

| Название | Содержимое |
|---|---|
| `Big Guy - Blue Signal Open (Price)` | Цена открытия сигнальной недели Blue. |
| `Big Guy - Yellow Signal Open (Price)` | Цена открытия сигнальной недели Yellow. |

Здесь выводится **цена только на свече обработки события**, на остальных свечах — `na`. Например, `80000`, затем пустые значения.

Наличие Blue само по себе ещё не означает, что началась О+Ф: для перехода код дополнительно проверяет открытое окно О+Ф. Эти ценовые события выводятся и до выбранного старта глобального тренда, если соответствующие даты есть в CSV.

**Две сетки: восемь ценовых плотов**

| Сетка | Названия |
|---|---|
| 4H | `Fibo 0 (Price)`, `Fibo 0.5 (Price)`, `Fibo 1 (Price)` |
| Big Guy | `Big Guy Fibo 0 (Price)`, `Big Guy Fibo 0.382 (Price)`, `Big Guy Fibo 0.5 (Price)`, `Big Guy Fibo 0.618 (Price)`, `Big Guy Fibo 1 (Price)` |

**Число в названии — коэффициент уровня. Значение самого плота — цена.** Например, `Fibo 0.5 = 80000` означает, что середина сетки находится на цене 80 000.

У сетки 4H ориентация зависит от направления её исходного построения и может отличаться от текущего `Phase - Direction`. У Big Guy уровень `0` всегда сверху, `1` — снизу. При отключении отображения соответствующей сетки её ценовые плоты становятся пустыми. Формирование значений — [здесь](</mnt/c/Users/G/Desktop/TV pine scripts/PifHist Monitor/PifHist Monitor Phase.md:2645>).

Например, одна строка данных:

```text
Global Trend - Direction        1
Global Trend - Half             2
Phase - State                   3
Phase - Direction              -1
Phase - Impulse Search Window    0
Phase - Active Entry Stop       na
```

читается так: **бычий глобальный тренд, его вторая половина; текущая фаза — О+Ф, активное направление медвежье, поиск 4H-входа закрыт, стоп текущей попытки не выведен.**

Есть и ограничение детализации: `Phase - State = 2` объединяет начавшуюся 4H-попытку импульса и подтверждённый импульс. Внутренний признак `impulse_entry_attempt` отдельно не экспортируется. Также нет отдельных плотов блокировки сетки, ожидания Yellow и времени начала каждой фазы.

| Название | Значения |
|---|---|
| `Guarantee Check - Bullish Pending (0 = Not Guaranteed; 1 = Guaranteed)` | `0` — гарантия не выполнена; `1` — выполнена. |
| `Guarantee Check - Bearish Pending (0 = Not Guaranteed; 1 = Guaranteed)` | `0` — гарантия не выполнена; `1` — выполнена. |
